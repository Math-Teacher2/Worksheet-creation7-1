# 맞춤형 학습지 생성기 (v10.1)

교과서 PDF를 올리면 AI가 교과서의 개념·문제·그림을 그대로 살린 학습지를 만들고,
**학생용 / 교사용(정답·풀이·지도 코멘트) HWPX(한글 문서)** 로 내려받을 수 있습니다.

## v10.1에서 바뀐 점 (실제 HWPX 교과서로 점검)
- **쪽 배경 그림에서 그래프 찾기**: 교과서 HWPX는 그래프·삽화가 쪽 전체 크기의 배경 그림(글자 없음)에 들어 있습니다.
  앱이 배경 그림에서 그래프 영역을 찾아 번호(P5-1 등)를 붙이고, 그 쪽에 그래프가 있을 때만 배경 그림 1장을 AI에게 보냅니다.
  학습지 그림은 배경 원본에서 잘라 내고, [✂ 위치 조정]도 배경 그림 위에서 할 수 있습니다.
- **글상자 안 제목 찾기**: 글상자 안의 큰 글씨(예: "거듭제곱과 거듭제곱근")를 제목으로 읽어 소단원 목차가 정확해집니다.
- **한글 수식 정리**: 글꼴 지정(rm·it·bold)과 띄어쓰기 기호(` ~)를 빼고 보내 토큰을 줄이고, 변환표에 TIMES·DIVIDE·pile·LDOTS 등을 추가했습니다.
- 여백이 0인 문서의 쪽 폭 계산 오류 수정, 옛 .hwp를 올리면 HWPX로 저장하는 방법을 안내합니다.

## v10에서 바뀐 점 (속도·안정성)
- **서버가 바쁠 때(503) 빨리 넘어가기**: 같은 모델로 6초 뒤 한 번만 다시 시도하고, 그래도 바쁘면 바로 다른 무료 모델로 넘어갑니다
  (예전: 10·25·50초를 기다린 뒤 전환 → 요청마다 1분 30초 낭비). 분당 한도(429)도 기다리지 않고 바로 넘어갑니다.
- **넘어간 모델 기억**: 한 번 넘어가면 약 20분 동안 다음 요청(목차·구성 분석·차시·검산)도 그 모델로 바로 시작합니다.
  예전에는 요청마다 붐비는 모델에서 다시 기다렸습니다. 모든 모델이 실패하면 다음에는 처음 고른 모델부터 다시 시작합니다.
- **기본값 조정**: Gemini 기본 모델 3.8 Flash → **3.6 Flash**(덜 붐빔), 생각 깊이 보통 → **빠르게**, 교과서 이미지 해상도 **보통**
  (속도·안정성 설정에서 "높음"으로 바꿀 수 있음), 차시 출력 상한 40k → 32k 토큰.
- **수식 정확도는 그대로**: PDF는 지금처럼 수식·그림을 쪽 이미지에서 읽고, PDF에서 뽑은 글자는 한글 문장 확인용으로만 씁니다.
- **HWPX(한글) 교과서·지도서 올리기**: PDF와 같은 칸에 올리면 형식을 알아서 판단합니다. HWPX는 글자·표·수식(한글 수식 문법)을
  그대로 읽고, 쪽 이미지 대신 쪽 안에 든 그림만 작게 보내서 토큰이 크게 줄고 수식이 깨지지 않습니다. 그림은 문서 안의 원본을 그대로 씁니다.
  쪽은 한글이 저장해 둔 줄 위치·쪽 나누기로 나눕니다. 옛 형식(.hwp)은 한글에서 "다른 이름으로 저장 → HWPX"로 바꿔 올리세요.
- **끌어다 놓기**: 교과서·내 학습지·레이아웃 참고 파일 모두 끌어다 놓거나 [파일 고르기]로 올립니다. 내 학습지 분석도 HWPX를 받습니다.

## v9.2에서 바뀐 점
- **처음부터 새로 시작(초기화)** 버튼: 만든 학습지·진행 기록·올린 파일을 지웁니다(AI 설정·키·구성·레이아웃은 그대로). 초기화하면 다시 열어도 이전 학습지가 뜨지 않습니다.
- **탐구 활동 따로 만들기**: 목차를 나눌 때 "탐구&융합·프로젝트" 같은 탐구 활동을 따로 표시합니다. 이 단원은 학습지 대신
  교사용 **탐구 활동 지도 자료**(활동 개요·진행 순서·예시 답안·평가)로 만들고, "학생 활동지도 만들기"를 체크하면 학생 개별 활동지도 만듭니다.
- **고난도 문항 역할** 추가: "교사 직접(빈칸)"이면 차시 끝에 문항을 붙여 넣을 칸을, "AI가 제작"이면 교과서 내용으로 고난도 문항 1~2개(정답·풀이 포함)를 만듭니다.
- 코넬 노트형의 왼쪽 이름 칸에 활동 이름을 줄이지 않고 그대로 표시합니다("생각 열기", "개념 도입" 등).
- 수식 밖 문장에 잘못 들어간 수식 명령(예: "바이트(\\text{Byte})")을 "바이트(Byte)"처럼 정리합니다.

## v9.1에서 바뀐 점
- 그림을 더 꼭 맞게: 잘라낸 그림 가장자리에 걸친 본문 문장(지도 Tip 문장 등)을 PDF 글자 위치로 찾아 잘라냅니다.
- 문제에는 문제 발문 안의 그림만: 예제 풀이 옆의 그래프, 지도서 여백(날개)의 해설용 그래프는 문제에 붙이지 않습니다.
  지도서를 올린 경우 여백의 그림 후보는 앱이 자동으로 걸러 냅니다.
- 문항 번호 중복 수정: (1)·（1）·⑴·$(1)$·[문제 1-(1)] 등 어떤 꼴로 와도 교과서 번호 하나만 표시합니다.
- 기본 구성의 "도입"을 "생각열기"로 바꿨습니다.
- 머리 표 등 제목의 수식이 $x$처럼 그대로 보이던 문제를 고쳤습니다(주변 글자 크기에 맞춰 표시).
- 학생용 빈칸을 더 크게(높이 1.22배, 너비 1.35배) 해서 쓰기 쉽게 했습니다. 교사용은 그대로입니다.

## v9에서 바뀐 점
- **교과서 그림을 정확하게**: 앱이 PDF 쪽에서 실제로 그려진 그림 영역(그래프·표·삽화)을 먼저 찾아 번호(P5-3 등)를 붙이고,
  AI는 좌표를 어림하는 대신 그 번호를 고릅니다. AI가 좌표를 직접 준 경우에도 가장 잘 맞는 실제 그림 영역에 맞춥니다.
  [✂ 위치 조정] 화면에서도 파란 점선 상자를 누르면 그 그림이 바로 선택됩니다.
- **교과서 또는 지도서 하나만 올리기**: 교과서/지도서 중 고르고 PDF 하나를 올립니다. 지도서를 넣으면 교사용에 정답 외에도
  지도 팁·교육과정 유의점·오개념·심화 참고를 넣습니다(학생용에는 교과서 내용만).
- **소단원별로 나눠 읽기**: 올리자마자 쪽마다 제목 글자만 읽어(가벼운 요청 1번) 소단원 목록과 쪽 범위를 만듭니다.
  소단원을 하나씩 만들고, 하나가 끝나면 "다음 소단원을 만들까요?"라고 묻습니다. PDF 전체를 한꺼번에 보내지 않아 토큰이 크게 줄고,
  대단원 전체를 돌리다 중간에 멈추는 일을 막습니다.
- **내 학습지 구성**: "내 학습지 올려서 분석" 또는 "기본 구성을 직접 정하기" 중 고릅니다. 올린 경우에는 분석 결과를 확인하고
  [이 구성으로 확정]을 눌러야 만들 수 있습니다. 역할 이름: 개념 도입·핵심 개념·확인 문제·예제·유제(또는 문제)·생각해보기/탐구해보기·실전 문제.
- **빈 공간 줄이기**: 한 차시는 2쪽 "이내"입니다. 1쪽에 들어가면 1쪽으로 만들고, 쪽을 채우려고 풀이 칸을 크게 늘리지 않습니다
  (문항당 최대 14mm까지만 늘리고 나머지는 쪽 아래 여백).
- **모델 목록**: 계열별로 2~3개씩(예: Opus 5.5·5·4.8, Sonnet 5.5·5·4.6). "직접 입력"은 없앴습니다(OpenAI 호환만 직접 입력).
- 문항 번호 중복("(1) (1)") 수정, 수식의 □(\\square) 표시 수정.

## v8에서 바뀐 점
- **구성 = 역할 + 이름**: 활동마다 "역할"이 보이고 바꿀 수 있습니다. 역할은 수학 교과서 흐름을 따른 8가지입니다
  (도입 → 개념 도입 예시 → 개념 정리 → 확인하기 → 예제 → 풀이 전략 → 문제·유제 → 생각해보기).
  이름은 학습지에 찍히는 글자일 뿐이라, 이름을 바꿔도 AI가 넣는 내용은 역할대로입니다.
  (v7까지는 역할이 화면에 보이지 않아, 이름만 바꾸면 "문제" 역할에 "핵심 개념"이라는 이름이 붙는 식으로 어긋났습니다.)
- **구성 분석 개선**: 단원명·주제명("수열의 수렴", "정적분의 활용")을 활동 이름으로 읽지 않습니다. 이름표 없이 시작하는
  예시·개념 부분은 역할만 정하고, 판단 근거를 각 줄 아래에 보여 줍니다. v7 이하에 저장된 구성은 기본 흐름으로 바꿔 불러옵니다.
- **생성 지시 개선**: 교과서의 각 요소를 성격에 맞는 역할 하나에만 넣도록 했습니다(도입 문항을 개념 정리에 넣거나,
  개념 설명용 예시를 문제로 만들지 않음). 교과서의 채워 볼 표는 표로 옮기고, 빈칸은 핵심 용어·값에만 둡니다.
- **설정 정리**: "개념 설명(자세히/보통/간단히)"과 "빈칸 양"은 없앴습니다. 개념 설명의 양은 구성의 "개념 도입 예시"를
  켜고 끄는 것으로, 확인하기·예제·문제의 양은 구성 각 줄의 "문항 전부/대표 문항만"으로 정합니다.
- 이어지는 쪽 섹션 제목의 "(계속)"을 없앴습니다. 풀이 칸이 없는 쪽은 남는 공간을 한 칸에 몰지 않고 고르게 나눕니다.

## v7에서 바뀐 점
- **단원 전체를 안정적으로**: 먼저 축소 이미지로 "차시 계획"을 세운 뒤(가벼운 요청 1번) 차시마다 따로 만듭니다.
  - 끝난 차시는 바로 화면에 나타나고 브라우저에 저장됩니다. 오류가 나도 끝난 차시는 그대로 남습니다.
  - [이어서 만들기]는 남은(또는 실패한) 차시만 만듭니다. 차시마다 [↻ 다시]도 있습니다.
  - 새로고침하거나 창을 닫았다가 같은 교과서 PDF를 다시 올려도 이어서 만들 수 있습니다.
- **오류 이유 설명**: 503(서버 바쁨), 429(분당·하루 한도), 키 오류, 출력 길이 초과, Gemini의 RECITATION(교과서 문장 반복 차단),
  네트워크 끊김 등을 종류별로 구분해 이유와 해결 방법을 보여 줍니다. "자세히"에서 원문 메시지도 볼 수 있습니다.
- **자동 복구**: 서버가 바쁘면 10초·25초·50초 간격으로 다시 시도하고, 계속 바쁘면 같은 회사의 다른 모델로 전환합니다(끌 수 있음).
  RECITATION이면 설명을 학습지 문체로 바꿔 쓰게 해서, 출력이 잘리면 더 간결하게 해서 한 번 더 요청합니다.
- **연산 줄이기**: AI 생각 깊이(빠르게/보통/깊게), 이미지 해상도(교과서 높음·지도서 보통·차시 계획 낮음)를 나눠 씁니다.
  화면에 예상 요청 수와 실제 사용 토큰을 보여 줍니다. 검산을 끄면 요청 수가 절반입니다.
- **교사용 교과서·지도서(선택)**: 지도 TIP·지도 방향·유의점은 교사용에만 작은 코멘트 상자로 넣습니다.
  고등학교 범위를 넘는 "참고" 내용은 "심화 참고(교육과정 밖)"로 교사용에만 넣습니다.
  지도서 내용으로 "생각해보기" 질문을 만들고, 인쇄된 정답으로 정답을 확인합니다.
- **교사용 글씨 자동 조절**: 학생용과 교사용은 쪽마다 같은 표(블록)를 담고, 높이는 각자 맞춥니다.
  교사용 글이 많아 쪽을 넘치면 해설·지도 코멘트만 93%→86%→78%로 줄입니다.
- "개념 정리(네모 빈칸) · 개념 정리(네모 빈칸)"처럼 제목이 겹치던 문제를 고쳤습니다(괄호 설명은 활동 특징으로만 씀).

## 이전 판의 기능
- 여러 AI 선택(Gemini·Claude·OpenAI·OpenAI 호환). API 키는 각자 브라우저에만 저장됩니다.
- 내 학습지 구성 분석·편집, 기출문제·수능특강 교사 작성 쪽, 레이아웃 5종 + 레이아웃 참고 파일 분석.
- 한 차시 = A4 정확히 2쪽, 표가 쪽을 넘지 않게 맞춤, 한글 수식 편집 지침 반영.
- 교과서 그림 잘라 넣기([✂ 위치 조정] / [+ 그림]), 정답 검산, AI 수정 요청, 내용 직접 고치기.
